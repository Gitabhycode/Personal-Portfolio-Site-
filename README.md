## ✨ About

This repository contains the source code of my personal portfolio website. It is a single-page, responsive web application that presents an introduction about me, the services I offer, the technologies I work with, my educational journey, and the major projects I've built. It also includes a **contact form** so visitors can reach out directly.

The site is designed with a clean, modern aesthetic and features a **dark / light theme toggle** for better user experience.

## 📄 What I Do (Site Features & Sections)

The site is a single-page application organized into the following sections:

- **🏠 Home** — Hero section with my name, title (Full Stack Developer), a short intro, and social links (GitHub & LinkedIn).
- **🙋 About** — Highlights my hands-on experience (1+ years) and provides a **Download Resume** button.
- **🛠 Services** — Lists the services I offer:
  1. Full-Stack Development
  2. Website Optimization
  3. API Integration
- **💡 Skills** — A visual grid of the technologies I work with (HTML, CSS, Bootstrap, JavaScript, React, Node.js, Java, MongoDB, Git & GitHub, Postman).
- **🎓 Resume / Journey** — A timeline of my education (BCA at Dr. CVRU Bilaspur Kota) and development experience.
- **📁 Projects** — A filterable gallery of major projects:
  - **Wanderlust Hotel Booking** — React, Node.js, MongoDB
  - **Spotify Clone** — HTML, CSS, JavaScript
  - **AI Resume Analyzer** — React, API, AI
- **📬 Contact** — A contact form for name, email, phone, and message.
- **⚙️ Interactive Features**:
  - Dark / Light theme toggle (saved in `localStorage`)
  - Smooth scroll animations using **GSAP ScrollTrigger**
  - Sticky header that changes background on scroll

## 🚀 Getting Started

This is a static website, so no build tools are required. You can run it directly in any modern browser.

### Option 1 — Open directly

Simply open the `index.html` file in your browser.

### Option 2 — Live Server (VS Code)

1. Install the **Live Server** extension in VS Code.
2. Right-click on `index.html` and select **Open with Live Server**.
